# flatfootlabs.com

The Flatfoot Labs website, served by GitHub Pages from `docs/`. It's a static site with no build step; `.github/workflows/pages.yml` deploys `docs/` on every push to `main`.

`docs/patches/` holds the current full patch and the update patches that the site's patcher and Update tab load. Patches for older versions are attached to each release of the game.

The source for *Pokémon Wishes of Tomorrow* is at [jmaloney95/Wishes-Game](https://github.com/jmaloney95/Wishes-Game).
